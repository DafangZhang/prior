# 先例（Prior）· UI 设计规格与实施计划（参考 motrix-mygo）

> 版本 v1.0 ｜ 状态：实施中 ｜ 上游：`PRD-FINAL.md` §13 前端规格、§14 逐页交互规格
> 参考项目：[missuo/motrix-mygo](https://github.com/missuo/motrix-mygo)（mygo 原生 UI 的复杂桌面工具范本）
> 本文是**实现级**设计：把 PRD 的形态裁决落到具体控件、令牌、菜单与键盘映射，并给出分期计划与每期验收。

---

## 1. 目标与范围

**目标**：把先例的界面语言、侧边栏操作、菜单体系、主显示区操作，按 motrix-mygo 的设计逐项对齐，并保持先例自身的产品语义（文档库 / 分析台 / 报告 / 历史 / 通知 / 设置）。

**范围内**：配色与令牌、窗口外壳、侧边栏结构与操作、菜单体系（页头菜单 / 行菜单 / 右键菜单 / 窗口菜单 / 命令面板）、逐页基础交互与样式、键盘映射。

**范围外（刻意不抄 motrix-mygo，理由见表）**：aria2 引擎面板、速度曲线与热力图、托盘与开机自启、自动更新、下载任务领域模型（先例是 PRD 比对工具，不做下载管理）。

## 4. 侧边栏：结构与操作功能

**结构**（自上而下）

1. 顶部留白 `titleBarHeight+4`（避开 macOS 红黄绿灯；`DragWindow()` 使空白处可拖窗）
2. 主导航：`文档库 · 分析台 · 报告 · 历史`
3. `ui.Spacer` 弹性空白
4. 次级：`通知`（未读徽标）→ `ui.Divider` → `设置`

**行样式**：`Height(38).Padding(0,10).Gap(10).Radius(8)`；图标 `FontSize(18)`；文字 14.5/500；徽标 `Padding(1,6).Radius(9).Background(accent).TextColor(accentText)`，数字用 `tnum`。

**状态**：默认无底色；`Hovered()` → `hover` 底；当前路由（含前缀匹配，如 `/report/1`）→ `active` 底。图标颜色：默认 `text`，选中不换色（底色承担选中语义）。

**操作功能（本设计确定的完整清单）**

| 操作 | 触发 | 行为 |
|---|---|---|
| 切换页面 | 单击行 | `router.Push(path)`；已在此页则不重推 |
| 悬停反馈 | 指针进入 | `hover` 底（同帧读取 `Hovered()`） |
| 收起 / 展开侧边栏 | ① 窗口控制键旁 chrome 按钮 ② `Cmd+Shift+B` ③ 命令面板 ④ 窗口菜单「视图 › 显示侧边栏」 | 写 `set.UI.SidebarHidden` 并持久化；`Animate("width")` 180ms；面板左边距 0→8 联动 |
| 徽标语义 | 报告 = findings 总数；通知 = 未读数 | 数字随 fixtures 实时计算，不硬编码 |
| 快捷跳转 | `Cmd+1..5` | 文档库 / 分析台 / 报告 / 历史 / 通知 |
| 提示 | 悬停 1s | `Tooltip` 显示「页面名 + 快捷键」 |
| 拖窗 | 在侧边栏空白处拖动 | `DragWindow()` |
| 配色 | 设置 › 外观 › 色板（8 色） | 即时改变窗口渐变与整体色调 |
| 侧边栏色点 | 状态栏右侧「知识库」药丸 | 见 §6.7（就绪 / 索引中 / 未连接） |

**合理性约束**：6 个页面不需要侧边栏内键盘遍历（`Cmd+数字` 更快）；不引入标签页 / 多窗口；不放用户头像与搜索框（搜索属于页面级）。

## 6. 逐页交互与样式

统一结构：`页头（标题 · 统计药丸 · 工具条 · 搜索开关）` → `内容区（列表 / 卡片 / 瓷砖）` → `状态栏`。页头 `DragWindow()`；侧边栏隐藏时整行下移到窗口按钮之下。

### 6.1 `/library` 文档库

- **结构**：表头（30px，可点排序，`ScrollWith(list)`）+ 虚拟列表 36px 行 + 右侧 inspector 280px。
- **列**：标题 · 格式 · 产品线 · 分块 · 状态 · 导入时间（时间在表内省略年份，inspector 保留全量）。
- **行**：奇偶斑马纹（`hover` 底）、悬停加淡底、选中 `accent` 底 + 白字，状态 `tone` 药丸（活跃绿/已替代灰/草稿琥珀）。
- **操作**：单击选中（联动 inspector）· 双击/回车 打开详情 · `Delete` 提示（占位）· 表头三态排序（升 → 降 → 默认）· 搜索 `Cmd+F` · 筛选/列/库级菜单 · 行右键。
- **inspector**：标题 15/600 + 状态药丸 + 「分析这篇 / 复制标题」+ `detail` 块（产品线/字符数/分块数/导入时间/状态）+ 分块预览（4px 进度条 + 计数）+ 原文预览（可选中）。
- **状态栏**：全部 / 活跃 / 已替代 / 草稿 计数 pills + 右侧详情面板开关。

### 6.2 `/analyze` 分析台

- **结构**：左列（拖拽区 → 主按钮「开始分析」→ 配置瓷砖 → stepper 瓷砖）+ 右侧「实时日志」瓷砖 300px。
- **拖拽区**：虚线边框；`FileDragOver()` 时边框与底色高亮；`DroppedFiles()` 入队并把文件名写入日志（本里程碑不接后端，队列仅记录）。
- **配置**：项目名输入 · 产品线文字 tab（`textTab`）· 模型 `Select` · 完成时通知 `Switch`。
- **stepper**：7 行竖排，序号 11.5/muted + 阶段名 13 + 已完成 `check`（success 色）+ 进行中「进行中...」（accent），行间 `sepLine`。
- **操作**：开始分析（主按钮）· 运行中「取消」· 失败「重跑」· 均写日志；页头工具条承载取消/重跑。
- **样式**：全部块用 `tile`；空态用 `emptyState`。

### 6.3 `/report/{runID}` 报告

- **概览瓷砖**：一行四数字（`Dividers` 分隔）+ 严重度图例与分布条 + run 信息行（运行/状态/耗时/命中文档）。
- **发现区**：类型文字 tab（4 类）+ 页头严重度筛选与排序菜单 + 搜索；卡片：严重度药丸 + 类型 + 置信度（`tnum`）+ 标题 15/600 + 详情 12.5/muted + 证据双栏（左 3px `down` 轨 = 新文档，右 3px `muted` 轨 = 历史文档，含引文与路径）+ 问题行（图标 + 文本）+ 操作行（确认/误报/待补充/搁置 + 复制）。
- **选中态**：`J`/`K` 上下移动选中，选中卡片左轨换 `accent`；单击卡片选中。
- **操作**：复制标题/详情；导出（占位）；重新分析 → 跳分析台。

### 6.4 `/history` 历史

- **结构**：卡片列表（状态药丸 + 时间 + 耗时 + 标题 15/600 + 严重度计数 + 操作行）。
- **操作**：打开报告 · 重跑（占位）· 复制标题 · 删除（占位）· 卡片 `⋯` 菜单与右键菜单同条目。
- **状态栏**：运行总数 / 已完成 / 失败。

### 6.5 `/notifications` 通知

- **结构**：卡片列表（未读药丸 + 时间 + `chevron-right` + 标题 + 「查看报告 / 标为已读」）。
- **操作**：页头「全部已读」· 卡片 `⋯`/右键「查看报告 / 标为已读 / 标为未读」· 点击 chevron 直达 `/report/{id}`。
- **状态栏**：通知总数 / 未读数。

### 6.6 `/settings` 与 `/settings/{section}` 设置

- **结构**：左侧分区列表 240px（标题 + 说明，选中 `active` 底 + chevron）· 右侧表单（`tile`，`MaxWidth(560)`，`Scroll`）· 底部草稿保存栏（有改动时出现，`Height(64)` + 顶分隔线）。
- **分区**：环境（DSN / Ollama）· 分析（嵌入模型 / LLM / 温度 / 上下文 / 超时）· 外观（主题 / 侧边栏配色 / 语言，即时生效）· 数据（隐藏列）· 关于。
- **操作**：`Cmd+S` 保存 · 页头 `⋯` 放弃/保存 · 离开未保存提示（切页时若有草稿则保留草稿并在页面顶部提示）。
- **样式**：`field()` 标签 + 控件；`Switch`/`Select`/输入统一 8px 圆角。

### 6.7 状态栏与「知识库」状态（跨页）

每页底部 `Height(52)` 状态栏：左侧本页计数 pills（`dot` + 文本，`tnum`），右侧「知识库」状态药丸：`dot` + 文案（就绪 / 索引中 / 未连接），并在提示中给出后端检查入口。数据源为本里程碑的 fixtures（后端接入后替换为真实连接状态）。

## 8. 实施计划（分期 + 验收）

每期结束执行**检查三件套**：`go build ./... && go vet ./... && go test ./...` 全绿；`ui.Render` 逐页出图并逐图核对（无裁切/重叠/错位）；每期一次 git 提交并推送。

| 期 | 内容 | 验收 |
|---|---|---|
| **P1 外壳与侧边栏操作** | 侧边栏项 `Tooltip`（含快捷键）· 窗口菜单「视图」· 状态栏「知识库」状态药丸 · 面板 hover/选中一致性核对 | 悬停有提示；菜单可切侧边栏/详情/主题；状态栏每页一致 |
| **P2 菜单体系** | 文档库 `⋯` 库级菜单 · 报告筛选/排序菜单 · 历史卡片 `⋯` + 右键 · 通知卡片 `⋯` + 右键 · 设置页头 `⋯` · 命令面板补充命令 | 每个菜单条目可用且选项 `Checked` 正确；右键与 `⋯` 条目一致 |
| **P3 主显示区操作** | 报告 `J/K` 选择 · 分析台拖拽高亮与入队 · 文档库行悬停 + 双击行为 · `Cmd+S` 保存/导出 · **修复设置草稿被每帧重置的缺陷** | 键盘可达；拖入文件有高亮与日志；设置改动不再丢失 |
| **P4 样式统一与文档** | 排版/间距/圆角全页核对与修正 · 状态栏与空态一致化 · 更新 `prd/README.md` 索引 · 全量检查 | 六页 + 收起态出图核对通过；测试全绿 |

**检查记录**：每期在本文末「实施记录」追加一行（期号 / 提交 / 检查结果）。

## 9. 合理性说明（与参考项目的取舍）

| 参考做法 | 先例是否采用 | 理由 |
|---|---|---|
| 侧边栏 200px + 图标 + 文字 + 徽标 | 采用 | 与 PRD §13.3 一致，信息密度合适 |
| 窗口渐变 + 可换侧边栏色相 | 采用 | 低成本的品牌感，且不影响可读性 |
| 表格列排序 / 显隐 / 斑马纹 | 采用（文档库） | 文档库是表格型数据 |
| 卡片行 + 状态药丸 | 采用（历史 / 通知 / 发现） | 这三处内容是"对象卡"，不是表格 |
