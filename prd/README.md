# 先例（Prior）PRD · 迭代档案

「先例」是一款**本地桌面 Agent**：把历史需求文档建成向量知识库；新产品文档提交时，自动检索相关历史文档并交叉比对，输出四类发现——逻辑漏洞、不明确的细节、一句话需求、变更信号与影响面。

形态：**mygo 原生 UI 桌面 App**（纯 Go 单二进制，无 webview / Electron / JavaScript），架构组织参考 [missuo/motrix-mygo](https://github.com/missuo/motrix-mygo)。

本目录记录该需求从原始想法到定稿的细化过程，每轮一份完整快照；每份轮次文件头部附「本轮变更说明」，可追溯每条设计的演化理由。

**读法建议**：直接读 `PRD-FINAL.md`（v1.1）；需要追溯某条设计由来时，按上表回查对应轮次。

**版本提示**：`round-3.md` 内的前端形态裁决（webview + React）已在第 6 轮被推翻，最终以 `PRD-FINAL.md` 与 `round-6.md` 的原生 UI 方案为准。

**全局基调**（各轮不变）：本地优先，文档数据不出本机；PostgreSQL + pgvector 做向量存储；本地 Ollama 提供 embedding 与 LLM；mygo 构建桌面 App（原生 UI）；中文优先（en / zh-Hans 双语）。
